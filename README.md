# CanITSM — Cinematic Animated Site

Dramatic scroll-driven remake of [canitsm.com](https://canitsm.com) content.

## Stack

- Vite + React + TypeScript
- GSAP + ScrollTrigger (pin, scrub, grow, landslide text)
- Lenis smooth scrolling

## Run

```bash
npm install
npm run dev
```

## Experience

1. **Intro** — logo spins in, theater curtains close into a square aperture, then open to reveal the site
2. **Scroll** — content enters from left / right / top / bottom
3. **Pinned grow** — page locks, frame scales up, advantage slides animate inside
4. **Process** — horizontal pinned scroll with tumbling cards
5. **Landslide text** — words/characters tumble into place like falling rock
